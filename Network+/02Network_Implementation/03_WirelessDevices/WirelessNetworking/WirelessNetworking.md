# 📡 Wireless Networking – Network+ (N10-009) – Section 2.3

## 🔗 Types of Wireless Networks
- **IBSS (Independent Basic Service Set)**: Ad-hoc connection, where two devices connect directly without an access point (e.g., IoT devices like door locks).
- **ESSID (Extended Service Set Identifier)**: Allows seamless roaming between multiple access points (e.g., large homes or businesses with several APs using the same SSID).

---

## 🔑 Key Wireless Identifiers
- **SSID (Service Set Identifier)**: The name of the wireless network (e.g., “SGC1”).
  - Multiple access points can use the same SSID for coverage over large areas.
  
- **BSSID (Basic Service Set Identifier)**: The hardware (MAC) address of the access point.
  - Each AP has its own unique BSSID, even if they share the same SSID.

---

## 🔄 Roaming Between Access Points (ESSID)
- Devices seamlessly move between access points with the same SSID (ESSID), staying connected without manual intervention.
- Example: Large building with multiple APs using the same SSID, ensuring uninterrupted service as the user moves around.

---

## 🔐 Captive Portal
- **Captive Portal**: A web page shown when connecting to a network, often used for authentication (e.g., at coffee shops).
  - Typically requires username/password or agreement to terms.
  - Access is time-limited (e.g., 24-hour access before re-authentication).

---

## 🔒 Wireless Security Types
- **WPA2 Personal**: Common security type for home networks (uses pre-shared key).
- **WPA3**: Newer, more secure protocol.
- **WEP**: Outdated, insecure.
- **OWE (Opportunistic Wireless Encryption)**: Allows connection but prevents device-to-device communication.
- **WPA, WPA2, WPA3 Enterprise**: Requires usernames and passwords, typically used in businesses (via 802.1x).

---

## 📡 Antennas
- **Omnidirectional Antenna**: Broadcasts signal in all directions. Ideal for home setups.
- **Directional Antenna**: Focuses signal in one direction for better range and performance (e.g., Yagi, Parabolic).
  - **Gain**: Measured in decibels (dB), with 3 dB doubling the signal strength.

---

## 💼 Enterprise Wireless Access Points
- **Autonomous AP**: Standalone device that does not require additional hardware or software to function.
- **Lightweight AP**: Relies on a central controller (Wireless LAN Controller) for management and configuration.

---

## 🧑‍💻 Wireless LAN Controller (WLC) & CAPWAP
- **CAPWAP (Control and Provisioning of Wireless Access Points)**: Standard for managing multiple lightweight APs from a central location.
- WLC provides:
  - Centralized management of AP configurations and monitoring.
  - Performance reports and configuration changes for all APs from a single interface.

---

## 💡 Key Takeaways:
- **IBSS**: Direct device-to-device connection.
- **SSID**: Network name; **BSSID**: AP hardware address.
- **ESSID**: Shared SSID across multiple APs for seamless roaming.
- **Captive Portal**: Web page for authentication (e.g., cafes, airports).
- **Security**: WPA2, WPA3, WPA3 Enterprise for business security.
- **Antennas**: Omnidirectional (360° signal) vs. Directional (focused signal).
- **WLC + CAPWAP**: Centralized management of enterprise APs.
