# 🔐 Wireless Encryption – Network+ (N10-009) – Section 2.3

### 🔒 Importance of Wireless Encryption
Wireless networks transmit sensitive data, so it's crucial to use encryption to protect confidentiality and ensure data integrity. Encryption methods help prevent unauthorized access to data, and integrity checks ensure that the received data is the same as what was sent.

---

### 🚫 WEP (Wired Equivalent Privacy)
- **WEP**: Early encryption method that was designed to provide security equivalent to wired networks.
- **Security Flaw**: WEP was found to have significant cryptographic vulnerabilities and is now considered obsolete.
- **Replacement**: WEP was replaced with WPA for better security.

---

### 🔑 WPA (Wi-Fi Protected Access)
- **WPA**: A temporary solution that replaced WEP but had its own limitations.
- Designed to work with the same hardware as WEP but introduced stronger encryption methods.
- It was considered an improvement but still not strong enough for long-term use.

---

### 🔒 WPA2 (Wi-Fi Protected Access 2)
- **WPA2**: Introduced in 2004 and remains widely used.
- **Encryption**: Uses **AES** (Advanced Encryption Standard) for data confidentiality.
- **Message Integrity**: Uses **CBC-MAC** (Cipher Block Chaining Message Authentication Code) for message integrity.
- WPA2 combined encryption and message integrity in a more secure protocol compared to WEP and WPA.

---

### 🔐 WPA3 (Wi-Fi Protected Access 3)
- **WPA3**: Introduced in 2018, it’s the latest and most secure version.
- **Encryption**: Uses **AES** for encryption, similar to WPA2.
- **Enhanced Integrity**: Introduces a more advanced encryption method, **GCMHP** (Galois Counter Mode with Hashing Protocol), and a stronger **GMAC** (Galois Message Authentication Code) for integrity checks.
- **Benefits**: Provides stronger protection, especially against offline password guessing attacks and ensures better security for both personal and enterprise networks.

---

### 🧑‍💻 Key Takeaways:
1. **WEP**: Obsolete due to vulnerabilities.
2. **WPA**: Temporary solution to replace WEP, but not the best long-term security.
3. **WPA2**: Stronger security using AES and CBC-MAC, still widely used.
4. **WPA3**: Latest and most secure, using AES and GCMHP for even better protection and integrity.

---

### 🔑 Recommendation:
- Always use the **highest level of security available** on both your access points and client devices.
- If possible, **upgrade to WPA3** for the best security on your network.
