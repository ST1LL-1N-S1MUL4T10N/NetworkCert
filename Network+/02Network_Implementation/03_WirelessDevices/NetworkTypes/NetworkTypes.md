# 📶 Network Types – Network+ (N10-009) – Section 2.3

## 🖧 Mesh Network
- **Mesh Network**: Multiple access points that communicate with each other to extend network coverage. Devices on the outer edges connect to these APs, which all mesh together.
  - **Self-healing**: If one device disconnects, the network automatically adjusts to maintain connectivity.

---

## 🔗 Ad Hoc Network
- **Ad Hoc Connection (IBSS)**: Two devices connect directly to each other without an access point.
  - Common for short-term or temporary connections (e.g., IoT devices).
  - Allows devices to communicate and share configurations, then connect to a larger network once configured.
  
---

## 📡 Point-to-Point Network
- **Point-to-Point Mode**: Used for long-distance wireless connections (e.g., connecting two buildings).
  - Requires access points that support this mode, specialized antennas, and sometimes higher power output to bridge the distance.
  - **Example**: Connecting two homes via wireless access points.
  
---

## 🌐 Infrastructure Mode
- **Infrastructure Mode**: Common setup for home and office networks.
  - Devices connect to a centralized access point, which also provides access to the wired network and other devices.
  - Security can be configured to either allow or isolate communication between wireless devices on the same network.

---

## 🧑‍💻 Key Takeaways:
- **Mesh Network**: Multiple APs that communicate and extend coverage, self-healing when devices disconnect.
- **Ad Hoc Network**: Direct device-to-device communication, often used in IoT setups.
- **Point-to-Point**: Long-range wireless connection between two locations.
- **Infrastructure Mode**: Centralized AP connects all devices, typical for home/office setups.
