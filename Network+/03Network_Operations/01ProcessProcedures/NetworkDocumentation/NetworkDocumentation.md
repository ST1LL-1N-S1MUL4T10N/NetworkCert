# 📝 Network Documentation – Network+ (N10-009) – Section 3.1

### 🌐 Types of Network Documentation

---

### 🗺️ Network Maps
- **Physical Network Maps**: Show the physical layout, including equipment, cabling, and connections.
  - Example: A physical map could show the internet connection going to a router, firewall, and core router, with specific IP addresses and physical connections.
- **Logical Network Maps**: Represent a high-level view of connectivity without focusing on specific cables. These maps show how different locations (e.g., buildings or sites) connect to a central point like a cloud.
- **Rack Diagrams**: Used to document the physical layout inside a rack in a data center. These diagrams allow technicians to know exactly where equipment is located and easily direct others to specific units.
- **Cable Maps**: Show how cables are routed through the office, often used in wiring closets (IDF/MDF). This documentation is helpful for both installation and troubleshooting.

---

### 🖥️ Layered Network Diagrams
- Combine **Layer 1** (physical layer), **Layer 2** (data link layer), and **Layer 3** (network layer) views.
  - **Layer 1**: Physical interfaces and cables.
  - **Layer 2**: MAC addresses.
  - **Layer 3**: IP addresses.
- These layered diagrams help you see the relationship between physical hardware and logical network connections.

---

### 📦 Asset Management
- **Asset Tagging**: Every piece of equipment (e.g., laptops, routers, switches) should be tagged with an asset label. These tags help in tracking the device’s purchase date, warranty status, and user assignments.
- **Asset Database**: A centralized database that tracks devices, including their location, user, and software configuration. This helps in warranty tracking and software license management.

---

### 🖧 IP Address Management (IPAM)
- IP address management tools allow you to **plan**, **track**, and **configure** IP addresses (both **IPv4** and **IPv6**).
- **DHCP and IP Address Schemes**: These tools help manage dynamic IP addressing and ensure there are no IP conflicts, shortages, or misconfigurations.
- **IPAM Console**: Provides a detailed view of subnetting, IP address usage, logs, and warnings to help administrators track and manage IP addresses efficiently.

---

### 📑 Service Level Agreements (SLA)
- **SLA Documentation**: Used to define the expected level of service from a service provider (e.g., **99.99% uptime**).
- **Downtime Management**: SLAs often include provisions on how quickly a provider will respond to service disruptions, ensuring minimal downtime for the network.

---

### 📡 Site Surveys and Wireless Documentation
- **Site Survey**: Used to document wireless access points, frequencies, and potential interference in the environment. This helps with optimizing wireless coverage and minimizing interference.
- **Heat Maps**: These maps are generated during site surveys to visualize wireless signal strength throughout a building or area. This ensures that the wireless network provides optimal coverage and avoids dead zones.

---

### 🛠️ Key Takeaways:
1. **Network Maps**: Physical, logical, and rack diagrams help visualize network layout and help with troubleshooting.
2. **Asset Management**: Asset tagging and centralized databases track devices, their location, and warranty status.
3. **IP Address Management**: Tools like IPAM track, plan, and optimize IP addressing and network configurations.
4. **Service Level Agreements**: SLAs define the required service levels from external providers, ensuring network reliability.
5. **Site Surveys**: Conducting site surveys and generating heat maps helps optimize wireless infrastructure and avoid interference.
