### 🔁 **File Transfer Protocols**
| **Protocol** | **Description** | **Port(s)** |
|--------------|-----------------|-------------|
| **FTP** (File Transfer Protocol) | Authenticated file transfer | TCP 20 (data), TCP 21 (control) |
| **SFTP** (SSH File Transfer Protocol) | Encrypted file transfer using SSH | TCP 22 |
| **TFTP** (Trivial File Transfer Protocol) | Lightweight file transfer (no auth) | UDP 69 |

### 📧 **Email Protocols**
| **Protocol** | **Description** | **Port(s)** |
|--------------|-----------------|-------------|
| **SMTP** (Send) | Send mail (unencrypted) | TCP 25 |

| **IMAPS** | Secure IMAP | TCP 993 |
